## 🚀 Quick Start

1. **Baixe** o instalador para Windows acima.
2. **Execute** o instalador (`super-gpt-*-win-x64.exe`)
3. **Login** na sua conta ChatGPT e Codex.
4. **Pronto!** 

## 🛡️ Jev Intelligence (System 1)

Jev is a lightning-fast semantic firewall powered by [TypeSafe](https://typesafe.ai):

- **Command Safety**
- **Smart Routing**
- **Context Filtering**
