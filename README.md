# ⚡ SUPER GPT

> Desktop control center with **Jev Intelligence** powered by TypeSafe.

SUPER GPT connects your ChatGPT account to Codex with full MCP tool support, plus an AI-powered semantic firewall (Jev) that judges command safety, routes actions, and scores context relevance — all in real time.

---

## 🚀 Quick Start

1. **Download** the latest release from [Releases](https://github.com/jubarthi/Super_Gpt/releases)
2. **Run** the installer (`super-gpt-*-win-x64.exe`)
3. **Login** to your ChatGPT account inside the app
4. **Done!** Start coding with AI superpowers

## ✨ Features

- 🔗 **Full MCP Support** — Connect ChatGPT to Codex with tunnel-based MCP tools
- 🛡️ **Jev Intelligence** — AI-powered command safety, smart routing, and context filtering
- 🖥️ **System Tray** — Runs silently in the background, always ready
- 🌍 **Multi-language** — English, Chinese, Japanese, Korean
- 🔄 **Auto-update** — Get the latest version automatically
- 🎯 **Codex TDS Connector** — Unique identity, runs alongside other Codex apps

## 🛡️ Jev Intelligence (System 1)

Jev is a lightning-fast semantic firewall powered by [TypeSafe](https://typesafe.ai):

| Feature | Description |
|---------|-------------|
| **Command Safety** | Scans every terminal command for destructive patterns before execution |
| **Smart Routing** | Classifies user intent to optimize which tools ChatGPT should use |
| **Context Filtering** | Scores file relevance so only critical context reaches ChatGPT |

To activate Jev, get your API key at [console.typesafe.ai](https://console.typesafe.ai) and paste it in the Jev section of the app.
